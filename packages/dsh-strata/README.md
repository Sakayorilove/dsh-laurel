# dsh-strata · 记忆地层

DeepSeek Harness 的本地跨会话记忆插件，当前版本 **0.2.0**。宿主运行时只使用 Node 内置模块，不需要向量服务或额外模型调用。

打开 **设置 → 记忆地层**，菜单包括：

- **范围与授权**：选择仅本会话／同工作区跨会话，独立开关全局记忆读取，逐个勾选其他工作区。
- **上下文力度**：轻量、均衡、深入预设，以及条数、字符、来源工作区和扫描会话上限。
- **记忆管理**：手工保存、搜索、遗忘长期记忆。保存时明确绑定工作区和会话。
- **召回预览**：检查相关片段、会话出处及实际注入文本。预览不消耗授权次数。

## 你描述的工作方式

在 A 工作区的会话 1 工作时，插件检索 A 的历史会话 2、3、4、5，并将相关片段与长期记忆一起排序。历史片段保留会话与事件编号，不会自动变成已确认的事实。

要查 B，在设置页勾选 B，然后让模型“查 B 工作区关于某件事的记录”。`memory_recall` 的 `workspace` 参数只限定来源，不能改变真实会话归属或创建授权。未勾选 B 时不检索 B 的正文。

**全局记忆和跨工作区授权是独立选项。** 全局记忆指明确保存为 `global` 的内容，例如通用个人偏好；勾选 B 是允许读取 B 的项目记忆与历史，不会把 B 的内容转换为全局。

## 设置建议与默认值

| 设置 | 默认 | 作用 |
|---|---|---|
| 会话读取范围 | 同工作区跨会话 | 可改为仅当前会话 |
| 读取全局记忆 | 开 | 可独立关闭 |
| 检索历史会话 | 开 | 引用历史，不自动写事实 |
| 跨工作区读取 | 仅已勾选 | 没有自动全局开放选项 |
| 新记忆保存范围 | 工作区 | 与读取范围独立 |
| 允许保存全局记忆 | 关 | 需由设置页开启 |
| 每次关联条数／注入预算 | 6 条／1600 字符 | 字符上限包含来源和资料边界 |
| 注入写入提示 | 克制 | 关／克制／均衡／积极。见下方说明 |
| 每次其他工作区／历史会话 | 最多 3 个／30 个 | 与逐工作区授权同时生效 |

**注入里为什么有一段"什么时候值得记"的规则。** 写入指令如果只写在 `memory_remember` 的工具说明里，模型在没有调用意图时看不到它；而记忆库为空时注入又整个不发生，于是形成死锁：没指令 → 不写 → 库还是空 → 还是不注入。实测代价是 4 天 0 条记忆。所以这段规则随注入块一起给出，**记忆库为空时也会注入**（此时块里只有规则，不含任何资料），并在规则里明确声明"这是插件规则，不是用户本轮的要求"。规则段算在注入预算之内；预算太小（约 400 字符以下）时规则段会让位给资料，保证出处和正文不被挤掉。不需要它就在设置页选"关"。

授权可选一次召回（5 分钟内）、本会话（绑定会话 ID，最长 12 小时）、长期。重复勾选会刷新额度；预览不消耗，一次实际召回即使有多条同工作区结果也只计一次。

取消勾选阻止后续读取；已经送入会话的内容仍会保留在该会话历史中。管理列表允许用户查看全部长期记忆，模型召回仍受范围和授权限制。

仅会话模式停止关联其他会话及其他工作区。全局读取仍由它自己的开关控制；需要完全隔离时，同时关闭全局读取。

## 安装与更新

本机 `desktop` profile 已通过 `link:` 连接本目录，更新源码无需重新安装。**宿主代码更新后，等正在执行的任务结束，再完全退出 Harness 并重新打开。** 设置入口为“记忆地层”。

其他机器请使用 Harness 的插件管理界面安装本地包或仓库；本项目尚未发布 npm 包。不要照搬本机绝对路径。

安装路径应保持稳定。本机在 WSL 的 `~/projects` 中构建和验证，通过校验后同步回已链接的安装目录，保留原版本备份。不要直接修改生成产物 `lib/client.js`。

## 模型工具

| 工具 | 用途 |
|---|---|
| `memory_recall` | 搜索长期记忆及已授权历史；可限定 `workspace`、`scope`、`limit`、`include_foreign` |
| `memory_remember` | 保存一条长期内容，默认绑定实际工作区 |
| `memory_forget` | 遗忘可修改的记录；`query` 仅预览 |
| `memory_link` | 关联两条可修改的记忆 |
| `memory_scope` | 检查范围／授权，撤销授权，提升自己的记忆；**不能创建授权** |
| `memory_stats` | 读取统计信息，并附**本地账本**：当前常驻注入块的字符/token、累计注入写入、交接落地、付费档真花掉的 token（宿主没有金额服务，故只报估算） |
| `memory_backfill` | 从当前工作区显式提取候选，默认只预览；不跨工作区写入 |
| `memory_handoff` | 把本次会话压成一条工作区交接记忆（结论＋最近原文＋一条 `memory_recall` 指路条）。**默认纯本地、零模型调用**；显式传 `summarize: true` 才花一次模型调用写真摘要，且花掉的 token 会回传并记进审计。压完不比原文短就不落地 |

跨工作区授权只读。禁止全局写入时，`memory_remember scope=global` 会明确降级为工作区保存；设置页全局保存及 `promote` 则拒绝操作并给出原因。

## 数据与边界

数据位于 `$DSH_HOME/strata/`，未设置 `DSH_HOME` 时使用用户目录中的 `.dsh/strata/`：

- `memories.jsonl`：追加式长期记忆，遗忘保留审计记录。
- `settings.json`：设置，临时文件写入并改名后才确认成功。
- `grants.json`：授权和使用次数，写失败不伪装成功。
- `events.log`：运行与注入数量记录。

历史读取优先使用宿主 `sessionQuery`。无该服务时读取当前版本的多帧 zstd 日志。可在 `extraSessionRoots` 指定备份会话根目录。扫描有数量、大小和等待上限；日志不存在、损坏或格式不支持时会跳过。

检索使用中文二元组、英文词、BM25、关联图和来源亲和度。没有相关词或图关联时不会仅因“最近使用”而注入。当前没有跨语言语义检索；换词或中英文标签能提高命中率。

本插件的授权约束自身记忆工具和自动注入，不能约束其他插件、宿主文件工具或已经获得文件访问权的命令工具。

## 开发与验证

所有开发命令在 WSL 中运行，使用 `pnpm`：

```bash
pnpm run build
pnpm run build:check
pnpm test
```

`pnpm test` 含 74 项原有冒烟断言和新增回归测试。HTTP 测试临时监听 `127.0.0.1` 的随机端口，使用隔离数据目录；受限沙箱可能需要本地端口权限。

`tests/ui.mjs` 使用真实 React 和 Chromium 验证设置页，在外部测试环境提供 React、ReactDOM、Playwright 即可；这些依赖不加入插件运行时。可通过 `STRATA_UI_DEPS`、`STRATA_PLAYWRIGHT`、`STRATA_CHROMIUM` 指定测试路径。

浏览器验证使用模拟宿主服务和真实插件代码；原生 Harness 的重启加载验收与浏览器验证分开记录，详见 [验证记录](验证记录.md)。
