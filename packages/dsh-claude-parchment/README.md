# Claude 羊皮纸 · DeepSeek Harness 插件

一套参考 2025 年 Claude 暖黄纸面气质的独立主题：日间是奶油羊皮纸，夜间是暖炭与旧纸，辅以陶土色操作按钮、衬线正文和清晰的无衬线界面。颜色是独立设计的近似值，不是官方 token 或像素级复刻；没有使用 Claude 标志、商业字体或商标素材。

1.3.0 保留原羊皮纸，新增 Robinhood · 荧绿、币安 · 石墨金、Bitget · 冰青三套简约交易终端外观。它们参考公开产品的美股／交易终端气质，采用无衬线正文、克制的单一强调色与少量交互光效；四套主题均有浅色与深色配色。没有加入品牌 logo、图片、字体资产或新的运行依赖，也不是相关品牌的官方主题。

1.3.1 进一步区分三套交易主题的形状：Robinhood 使用直角，币安使用小圆角，Bitget 使用柔和圆角与右下角收紧的聊天气泡；用户气泡与侧栏增加轻投影。输入框、导航、代码块和本主题设置内的按钮／路径输入框随所选主题调整圆角。原羊皮纸配色、圆角与阴影保持原样。切换方法与 1.3.0 相同，无需新增设置。

本插件只做一件事：**把外观换掉**。它不改消息内容、工具调用、滚动逻辑，也不读写任何其他插件的偏好或存储。

## 安装

本插件是一个标准 DSH 插件包，两种装法：

1. **从本仓库源码装**（改代码即生效）：在「设置 → 插件」里填本包目录的绝对路径
   （即本仓库的 `packages/dsh-claude-parchment/`）；或用装载机统一管理（见仓库根 `README.md`）。
2. **从 tgz 装**：先自行打包（`pnpm pack`）得到当前版
   `dsh-claude-parchment-1.3.1.tgz`，再把它的**完整绝对路径**填进「设置 → 插件」。

安装完成后按提示重启（如需要）。无需运行源码构建；本插件不修改任何其他插件的文件或存储。

### 选择主题（1.3.0）

安装后主题**默认关闭**。打开「设置 → Laurel总控 → Claude主题」；单独安装时，打开独立的「羊皮纸与交易主题」设置页。在四行原生单选项中选择 Claude 羊皮纸、Robinhood · 荧绿、币安 · 石墨金或 Bitget · 冰青，再打开「启用所选主题」。主题已启用时切换立即生效；关闭时只记住选择，下次启用时应用。

在「设置 → 通用 → 外观」选择浅色、深色或跟随系统；插件沿用这项设置，不创建另一套明暗偏好。字体大小继续使用 harness 的内容字号设置。旧版只有 `enabled`、没有 `theme` 的偏好会保留原启用状态，并回落到 Claude 羊皮纸；未知主题值也回落到羊皮纸。

源码与浏览器预览可验证四主题切换；预览使用模拟宿主服务，不能据此认定已在真实 Electron 会话启用。运行版本仍以设置页的「已加载版本」为准。

### 版本号与手动更新（1.2.0）

设置页标题旁显示当前运行的版本，下面同时显示 **已加载版本** 和 **已安装版本**：前者在构建时写入客户端，后者由 Harness 官方插件管理器读取。两个版本一致表示已加载对应安装版；不同则提示完整重启。无法读取时显示「尚未确认」和恢复方法，不会猜测更新已成功。「检查版本」只重新读取本机安装状态，不查询网上的最新版本。

以后拿到本插件的新版 tgz 文件，可以直接点「手动更新」，粘贴新版文件的完整绝对路径，再点「安装更新」。按钮调用 Harness 官方安装器，保留它的供应链检查与失败恢复机制；不会批准构建脚本或更改策略。安装完成后需要完整重启。重复版本、旧版本、相对路径、其他名称的包或远程 URL 会被拒绝；文件应保留 `dsh-claude-parchment-x.y.z.tgz` 这样的版本化名称。

### 对话排版（1.1.0）

对话与输入框共用居中的宽度轴，默认正文列宽 720px；窄窗口自动收缩，手动拖动的对话宽度仍沿用你的设置。回答采用 Georgia / 宋体等系统衬线字体、日间 1.8 / 夜间 1.85 的行距、一个字号的段落间距和更清楚的标题层级。用户消息改为柔和的 12px 圆角纸面块，消息之间留出 28px（窄屏 24px）。代码、工具按钮、折叠推理和操作标签保留等宽或无衬线字体。

## 自己改

```bash
npm run build     # 由 src/ 生成 lib/client.js（无依赖的浏览器插件产物）
npm test          # 单元与浏览器测试（浏览器测试需要 playwright）
npm run preview   # 本地预览页
```

`src/palette.mjs` 的 `themes` 定义四主题的完整浅／深色配色；原 `palettes` 仍指向羊皮纸配色。`src/theme.css` 定义只在本插件自己的 `data-cp-active` 属性下生效的外观，并通过 `data-cp-theme` 应用主题差异；`src/runtime.mjs` 管理独立的启用与主题偏好，`src/updater.mjs` 调用官方安装 API 并验证版本，`src/client.js` 注册官方 ModuleLoader 协议与设置入口。`lib/client.js` 是可直接加载的产物。

少量欢迎标题、导航与发送按钮的 CSS 模块类名按本机 harness 0.2.0-rc.2 的实际结构编写；宿主升级后类名若变化，这些细节会退回原生样式，颜色覆盖仍使用公开主题 API。

## 设计来源

2025 年视觉参考入口：[Anthropic 的 Claude 3.7 Sonnet 发布资料](https://www.anthropic.com/news/claude-3-7-sonnet)与 [Claude 的 Integrations 发布资料](https://claude.com/blog/integrations)。实现依据本机 harness 的公开结构与公开主题 API，未对任何历史界面作逐像素校准；不包含任何第三方插件的代码或品牌素材。

1.3.0 风格参考：[Robinhood Legend](https://robinhood.com/us/en/legend/)及其[布局说明](https://robinhood.com/us/en/support/articles/layouts-on-legend/)、[币安交易页主题与布局说明](https://www.binance.com/en-GB/support/faq/how-to-customize-the-trading-page-theme-and-layout-70bf06528a9948c2afae16b8390e9d54)、[Bitget 公开产品页](https://www.bitget.com/)。本次查阅的是官网公开文字，只借鉴简洁终端、层级与强调色方向；未复制其源码、提取官方 CSS token 或声称看过演示视频。实际配色以本包 `src/palette.mjs` 为准。
